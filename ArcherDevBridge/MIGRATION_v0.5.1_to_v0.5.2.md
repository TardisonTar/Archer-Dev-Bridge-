# Migration 0.5.1 → 0.5.2

Обновление совместимо с существующими настройками, task queue и логами в `%LOCALAPPDATA%\ArcherDevBridge`.

Что меняется:

1. Новые development run сохраняют полный набор диагностических артефактов Codex.
2. `last-gate.json` указывает на реальный run-каталог даже при исключении после его создания.
3. «РАЗОБРАТЬСЯ» читает последний Quality Gate и доступные `failure-summary/stdout/stderr`.
4. В System Health добавлена строка последнего цикла и кнопка просмотра причины.
5. Старые FAIL без артефактов не восстанавливаются задним числом; Bridge явно помечает их как созданные до 0.5.2.

Системный PATH, credentials и Git history обновление не изменяет.

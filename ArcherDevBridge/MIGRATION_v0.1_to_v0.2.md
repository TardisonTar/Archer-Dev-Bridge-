# Переход с v0.1.0 на v0.2.0

1. Распакуйте v0.2.0 в новую папку рядом с v0.1.0.
2. Запустите `START.cmd`.
3. Снова выберите игровой репозиторий.
4. Godot обычно найдётся автоматически (`C:\Tools\Godot\godot.exe`).
5. API key переносить не нужно: Bridge его не сохраняет.
6. Убедитесь, что в игре есть `PROJECT_RULES.md` и `ARCHITECTURE.md`.
7. При желании скопируйте `AGENTS.md.template` в корень игры как `AGENTS.md`.
8. Перед первым циклом нажмите `Проверить окружение`, затем `Только Quality Gate`.

v0.1.0 можно оставить как резервную копию. Никакие файлы игрового проекта при установке Bridge автоматически не изменяются.

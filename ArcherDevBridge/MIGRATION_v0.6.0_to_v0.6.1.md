# Migration 0.6.0 → 0.6.1

Обновление не меняет формат настроек или run schema.

Установщик автоматически:
1. сохраняет `%LOCALAPPDATA%\ArcherDevBridge` с настройками/очередью/логами;
2. закрывает открытое окно Archer Dev Bridge, если оно мешает обновлению;
3. заменяет файлы программы;
4. создаёт/обновляет ярлык `Archer Dev Bridge` на реальном Desktop и в Start Menu;
5. запускает `ArcherDevBridge.exe`.

Пользовательская командная строка не требуется.

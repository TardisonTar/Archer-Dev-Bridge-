# Migration 0.4.0 → 0.4.1

Установка поверх 0.4.0 поддерживается. Каталог программы заменяется, но настройки и логи в `%LOCALAPPDATA%\ArcherDevBridge` сохраняются.

Новые поля `codexPath`, `gitPath`, `dotnetPath` добавляются в `settings.json` автоматически после обнаружения инструментов. API key по-прежнему не сохраняется.
